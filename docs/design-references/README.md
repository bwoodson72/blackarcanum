## Interpretation

- The final public brand is **Mystagogia**; domain to be selected later.
- Use the approved homepage mockup for palette/typography/editorial rhythm and `docs/DESIGN_SYSTEM.md` for semantic token rules.
- Use the responsive mockup and Specification §16 for mobile-first behavior; preserve reading width instead of compressing a three-column article layout.
- Shop must emphasize **actual apparel and other legitimate Printful merchandise**. Books/digital content remain optional and must not be invented.
- Match design intent, not source mockup pixels. Accessibility, real data, responsive behavior and licensing outweigh decorative fidelity.
- Production fonts and graphics must be legally sourced/created during their assigned implementation step. For new image generation, obtain the owner's approval of the concept first.

These previews are compressed WebP for GitHub review (full-resolution PNGs live in the Mystagogia workspace). If a visual judgment depends on small text or fine ornamentation, inspect the corresponding full-resolution original before implementing.
